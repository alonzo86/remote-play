A chunky sticker button: fill, 6px dark outline, hard shadow, fully rounded to `radius-lg`.

Provide the label; keep it short, it is only as wide as its text. Variants: default (`button` fill, white text), primary (`accent` fill, `card-text`, one per screen for the main action), secondary (quiet `bg-dark` with a 4px dimmed outline, only for Back). Focus (D-pad) and hover swap the outline to 10px `accent`; the size never changes. A click or tap leaves no focus. Disabled is flat `disabled`, no shadow. Do not use yellow text on a button.
