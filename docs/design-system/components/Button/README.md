A menu item: text with a pixel cursor in front of it when it has the focus. There is no box.

Provide the label in upper case. `text` normally, `accent` with the focus and a cursor drawn as pixels (four columns of 7, 5, 3 and 1 pixels), `bad` with the focus for a destructive item (END GAME, QUIT, REMOVE), `text-dim` for a quiet item (BACK) until it has the focus, and `text-dim` with no cursor for a disabled item. A choice never depends on color alone: the cursor shows the focus. On the phone a button is a framed text box instead (a 6px `text` line, `accent` with the keyboard focus, filled when pressed), because a touch screen has no cursor. Every state has 4.5:1 or more on `bg`.
