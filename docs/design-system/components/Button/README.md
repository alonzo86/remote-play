A chunky sticker button: fill, 6px dark outline, hard shadow, fully rounded to `radius-lg`.

Provide the label; keep it short, it is only as wide as its text. Three colors, all with the hard shadow: default `accent` yellow, primary `ok` green (the main action of a screen), danger `danger` red with white text and a ✕ (confirmations only). Text on yellow and green is `card-text`. `row` is the purple row button (settings rows, badge, gear). `secondary` is the quiet `bg-dark` button for Back; it turns light when focused. Focus (D-pad) and hover: a 10px black `focus-border` and a longer shadow (the button lifts, its size never changes). Pressed: the shadow goes and the button moves onto it (it sinks). A click or tap leaves no focus. Disabled is flat opaque gray (`disabled`), no shadow, never see-through. A color never carries the meaning alone: green and red buttons say what they do in words.
