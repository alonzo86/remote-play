A framed box in the top right of the Games screen with four squares and the player count, for example "2P".

Provide the slot states; the squares use `player-1` to `player-4`, empty slots `slot-empty`. It does not show the room code. The frame is `text-dim`, `accent` with the focus. OK opens the players modal. OPTIONS next to it is a framed text box of the same kind.
